# Data

Reusable datasets compiled during research, so future issues do not start from zero.

Planned files:

- `competition-calendar.md`: every verified SA entrepreneurship competition and funding programme, with deadlines and source URLs (built in Phase 2). Feeds The Wire every week.
- Funding programme datasets (SEFA, SEDA, NYDA, DSBD, IDC, TIA and private funds) as they are compiled for Capital articles.

Rules: every row in every dataset must carry a source URL and the date it was accessed. No unsourced entries.
